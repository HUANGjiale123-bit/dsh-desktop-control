## 本轮（2.18.80）修的四项

1. **启动恢复的结果判断**：改用 `runHelperJson`，与卸载路径共用
   `restoreConfirmed(r)`（`r.ok === true && r.data?.ok === true`）。失败/超时/空响应
   一律保留标记并记"未确认"；删除前再核验标记没有被新实例替换。
2. **GC 跳过待恢复目录**：含 `fx.blanked` 的实例目录不再被"1 小时回收"删除。
3. **runner 判定**：任何子测试非零退出、或输出有 ✗ 但汇总写 0 失败，都让整体失败。
4. **默认测试副作用**：`test-ready-check` 只杀自己创建的 guard（去掉全局按名强杀）；
   `test-cursor-stale-recovery` 改用私有目录 + 恢复替身，不再碰真实 `%TEMP%` 和系统光标。
