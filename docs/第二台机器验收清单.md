# 第二台机器验收清单

> 目标：在一台**没装过这个插件**的机器上，判断"装上了"之外，它到底**能不能用**。
> 自动能测的交给脚本，剩下需要人眼判断的列在下面。
>
> 预期耗时：25 分钟（其中 5 分钟是等超时和长稳观察）。

---

## 0. 先跑体检脚本（1 分钟，结果整段贴回来）

在仓库目录执行：

```
node tools/smoke-report.mjs
```

它会把**能自动采的**都采下来：插件版本、helper 完整性级别、DPI 感知、
系统版本、屏幕分辨率与缩放、光标尺寸、OCR 语言包、光标素材数量、闸门状态。

**重点看三项**：

| 项 | 期望 | 不对的话 |
|---|---|---|
| 完整性级别 | `Medium` | `Low` → 鼠标注入会静默失效，整个插件等于废的 |
| OCR 语言包 | 至少有 `zh-Hans-CN` 或其它 | 空 → 视觉兜底不可用（不影响基础操作） |
| 光标素材 | `10 张` | 少于 10 → 安装包不完整 |

---

## 1. 基础：能不能点准（5 分钟）

**测什么**：坐标换算在这个缩放比例下对不对。这是最容易在第二台机器上翻车的地方。

1. 打开记事本，让它显示最大化
   （`desktop_launch_app` **必须给完整路径** `C:\Windows\System32
otepad.exe`——
   应用清单来自注册表，记事本没登记，按名字会报"没有匹配"）
2. 让 DSH：`用 desktop_click 点 (x, y)`，坐标选记事本里一个**看得见的按钮**（比如"文件"菜单右上角）
3. 观察：菜单是否弹出

再补一个更精确的：

4. 让 DSH 截一张图给你（`desktop_screenshot`）
5. 你在图上找一个**特征点**（比如某个字），告诉它"点截图上的这个字"
6. 看它算出来的落点是不是你说的那个字

**记录**：点中了 / 偏了（偏几个像素、往哪个方向）。

---

## 2. 按名字点（2 分钟）

在记事本里：

> 用 `desktop_click_element` 点"编辑"菜单

**期望**：直接命中，不需要坐标。失败时会告诉你"没找到这个名字"，并列出实际有哪些名字——
把那段贴回来，我能判断是名字匹配的问题还是树读不到。

---

## 3. 视觉兜底（5 分钟）

打开**画图**（mspaint），随便用文字工具写两个字（比如"测试"），然后：

> 用视觉兜底找到"测试"两个字并点它

**期望**：先列出 OCR 候选，再点击，落点在那个字上。

**记录**：OCR 识别到的文字是否正确（中文识别很依赖语言包）。

---

## 4. 遮挡行为（1 分钟）

用另一个窗口盖住目标窗口的一半，然后截图。

**期望**：明确警告"截图可能被遮挡"，而不是静默拍成遮挡者的画面。
如果它照常截图、什么都没说 —— 这是 bug，要报。

---

## 5. 急停（3 分钟）

1. 让它开始一个操作（比如拖拽）
2. 操作过程中按 **ESC**
3. 之后随便让它点一下

**期望**：第二次被拒绝，提示"闸门生效"。
4. 对它说"继续"，让它调 `desktop_resume`
5. 再点一次

**期望**：恢复正常。

---

## 6. 光标彩蛋（5 分钟，可选）

先在 `%TEMP%` 建空文件 `dsc-cursor-fx.enable`，重启 DSH，然后随便做一次桌面操作。

| 检查 | 期望 |
|---|---|
| 光标形状 | 变成画里的箭头 + 鲸鱼 |
| 形状跟随 | 移到文字上变 I 形、移到按钮上变手形 |
| 箭头尖对齐 | 箭头尖正好在你指的位置（不是偏一格） |
| 停手 30 秒 | 系统光标自动回来 |
| 强杀装饰进程 | 任务管理器结束 `dsc-fx.exe` → 0.5 秒内光标恢复 |

**如果光标一直不回来**（看门狗也没救到）：
控制面板 → 鼠标 → 指针 → 随便选一个方案 → 应用。

---

## 7. 卸载（2 分钟）

在插件管理里移除插件，重启 DSH。

**期望**：
- `desktop_*` 工具全部消失
- 任务管理器里没有 `dsc.exe` / `dsc-esc.exe` / `dsc-fx.exe` / `dsc-guard.exe` 残留
- 系统光标正常

---

## 8. 卸载（2 分钟）

**顺序很重要**：直接 `pnpm remove` 会留下悬空的 bundle 引用，DSH 可能起不来。

1. 先从 profile 的 `package.json` → `dsh.profile.bundles` 里**移除** `"dsh-desktop-control"`
2. 再 `pnpm remove dsh-desktop-control`
3. 重启 DSH
4. 验证三件事：
   - `desktop_*` 工具全部消失
   - 任务管理器里没有 `dsc.exe` / `dsc-esc.exe` / `dsc-fx.exe` / `dsc-guard.exe` 残留
   - 系统光标正常

## 9. 长稳（可选，挂 30 分钟）

装回去，让它隔几分钟做点操作，观察：
- 任务管理器里 `dsc-fx.exe` 的 CPU（应该 <2%）
- 内存是否一直涨

---

## 出问题时贴什么回来

| 情况 | 需要的东西 |
|---|---|
| 装不上 / 起不来 | `node tools/smoke-report.mjs` 的输出 |
| 点偏了 | 那张截图 + 它算出的坐标 + 你实际点的位置 |
| 视觉兜底不行 | OCR 候选列表 + 语言包信息 |
| 光标异常 | `%TEMP%\dsc-cursor-fx\fx.log` 和 `guard.log` |
| 工具报错 | 错误原文（我们的错误信息带错误码，比如 `失败：Refused — ...`） |
